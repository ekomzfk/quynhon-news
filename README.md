# Новостной бот: Куинён + Вьетнам для экспатов

Каждые 10 минут бот проверяет, нажали ли вы кнопки на черновиках, и сразу публикует одобренное.
Раз в час он собирает новости, Claude отбирает интересное, читает полный текст статьи и пишет
подробный пересказ на русском (и английском, если включить).

## Настройки (файл .github/workflows/news.yml)

| Параметр | Что делает |
|---|---|
| `RU_CHANNEL` | ваш канал (`@Quynhon_news`) |
| `EN_CHANNEL` | английский канал; пусто = выключен |
| `ADMIN_CHAT_ID` | ваш Telegram ID, сюда приходят черновики |
| `MODERATION` | `1` = черновики с кнопками, `0` = публиковать сразу |
| `MIN_SCORE` | порог интересности для новостей Вьетнама (0–10) |
| `MIN_SCORE_LOCAL` | порог для новостей Куинёна (мягче) |
| `MAX_POSTS_PER_RUN` | сколько черновиков/постов максимум за час |
| `QUIET_HOURS` | ночью не публикует (время Вьетнама); `off` = круглосуточно |
| `MODEL` | `claude-haiku-5-5` дешевле, `claude-sonnet-5-5` пишет лучше |

Меняйте только текст внутри кавычек, пробелы в начале строк не трогайте.

## Источники (файл sources.py)

Gia Lai News (публикуется всё), Báo Gia Lai, Google News по «Quy Nhơn», VnExpress International,
SGGP News, LuatVietnam (законы), Лаодонг (по-русски), Google News про визы и иностранцев.
`publish_all: True` у источника означает «публиковать всё без отбора».

Если какой-то сайт сменил вёрстку, в логе будет предупреждение, а остальные источники
продолжат работать.

## Если что-то не работает

- `chat not found`: бот не админ канала, или вы не написали боту `/start`.
- `Не заданы настройки`: проверьте имена секретов, буква в букву.
- Ошибка в шаге Save state: Settings → Actions → General → Workflow permissions →
  Read and write permissions.
- GitHub иногда запускает расписание с опозданием. Это нормально.
